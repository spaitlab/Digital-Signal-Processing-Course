# 课件

本目录将收录经整理的正式教学版 PPTX 与 PDF。当前尚未上传课件。

## 目录与命名

按 `第01章/` 至 `第07章/` 整理；建议文件名为 `DSP-第01章-概述-2026-2027-1.pptx`，PDF 使用同名。

每个章节保留明确的当前教学版。学期定稿通过仓库版本标签和网盘下载包归档，避免将历年重复版本混入当前教学目录。

## 微课入口

在相应知识点页加入微课封面、观看链接和二维码，统一指向对应的课程网站微课页面。网站页面尚未发布时，不生成假定有效的二维码。

课堂播放可使用教师本地保存的视频。PPTX、PDF 对外提供的观看链接以浏览器打开课程页面为准。

## 导入检查

- 确认章节、教学版本与素材来源。
- 排除 Office 临时文件及教师专用答案。
- 检查幻灯片备注中是否含有不应公开的资料。
- 核对 PPTX 和 PDF 中的链接、中文与公式显示。
