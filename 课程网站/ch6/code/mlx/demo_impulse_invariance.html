演示3：频率响应是 Ha(jΩ) 的周期延拓之和（教材式 (6.2.1)(6.2.2)）：Ha 不带限，T 越大混叠越重

aliasRel = max(abs(Hd - Hone), [], 2).' ./ max(abs(Hd), [], 2).'; % 混叠相对大小
