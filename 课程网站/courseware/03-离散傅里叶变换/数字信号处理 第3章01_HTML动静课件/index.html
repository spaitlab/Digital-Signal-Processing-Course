课程来源与模型约定

范围依据去年《数字信号处理 第3章01》PPTX（11 页）与课程网站 3.1 四种傅里叶变换。讲解配音从已有 3.1 微课逐段剪辑，字幕独立整理，未使用教师声音复刻。

连续模型为宽 3 s、幅度 1 的中心矩形脉冲；离散模型为 x[−1] = x[0] = x[1] = 1，其余为零。它们属于同类脉冲，不将连续傅里叶变换与离散傅里叶变换数值直接等同。浏览器按解析式实时计算，显示窗口外的信号按各模型定义延续。

连续时间频率 Ω 单位 rad/s，离散时间频率 ω 单位 rad/sample。FS 显示系数幅度 |cₘ|；周期对照页显示 T|cₘ|；DTFT 与 DFS 在本实偶例子中显示带符号实值。DFS 正变换不除以 N，逆变换带 1/N。n、k 为索引，N 为周期长度。
