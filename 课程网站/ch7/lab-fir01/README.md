# FIR-01 四点滑动平均实验

先阅读 [学生实验任务单](学生实验任务单.md)，记录预测后运行实验。

```shell
python -m pip install -r requirements.txt
python run_lab.py
python run_lab.py --taps 8
```

MATLAB 使用 `run_matlab_fir.m`，MWORKS / Julia 使用 `run_syslab_fir.jl`。请在下载的实验目录内运行，图和结果写入本地 `results/`。
