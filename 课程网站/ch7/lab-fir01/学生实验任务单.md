# 实验 01：四点滑动平均 FIR——预测、仿真与跨平台核验

本任务单为课程原创实验，不是教材原文或指定书中例题的复制。建议 50 分钟，20 人分成 10 组，每组 2 人，预测者与操作员中途交换。默认使用 Python；教师演示 MATLAB、MWORKS 对照。

完成后，你应能写出差分方程，预测特定频率的增益与延迟，识别启动瞬态，并用数据验证不同平台是否实现了同一系统。

## 1. 概念讲解（8 分钟）

四点滑动平均使用当前与过去三个样本：

$$
y[n]=\tfrac14(x[n]+x[n-1]+x[n-2]+x[n-3]),\qquad x[n]=0\ (n<0).
$$

冲激响应为 $h[0..3]=[1/4,1/4,1/4,1/4]$，其余为零。它有 4 个抽头、阶数为 3，是因果 FIR。每来一个新样本，就更新一次输出。

$$
H(e^{j\omega})=\tfrac14\sum_{k=0}^{3}e^{-j\omega k}
=e^{-j3\omega/2}\frac{\sin(2\omega)}{4\sin(\omega/2)}.
$$

其中 $\omega=2\pi f/f_s$。直流点的分式取极限，增益为 1；其他点需关注幅值及符号。一般 M 点平均的群延迟为 $(M-1)/2$ 个采样间隔，在频响零点处相位和群延迟没有定义。

课堂讨论：平均四个样本为什么会平滑波形？“平滑”是否意味着所有高频都消失、低频完全不变？

## 3. 实际仿真（12 分钟）

进入本实验目录，在终端运行（Python 3.10+，已安装 NumPy、SciPy、Matplotlib）：

```powershell
python run_lab.py
```

需要首次安装依赖时，使用自己的课程虚拟环境执行 `python -m pip install -r requirements.txt`。无需 API key、WeKnora 账号或教材原文件。脚本只在本实验目录写入结果。

打开 `results/python-overview.png`，观察稳态波形、冲激响应、幅频响应、起始样本四幅图。`results/python.csv` 保存全部 2001 个样本，`python-metrics.json` 保存拟合指标及验证结果。

核心实现是 `lfilter(np.ones(4)/4, [1.0], x)`。另用差分方程、冲激与阶跃响应、解析稳态表达式交叉核验。不得用居中平均、`convolve(..., mode='same')` 或 `filtfilt` 替代本实验的因果零状态滤波。

拓展试验：每次只改一个参数，并先预测再运行。

```powershell
python run_lab.py --taps 8
python run_lab.py --f2 200
```

拓展结果写入 `explorations/`，不会覆盖四点基线。回答：8 点平均是否一定更好？为何 250 Hz 换成 200 Hz 后不再完全消失？

## 4. 结果比较（12 分钟）

教师运行随包 `.m` 与 `.jl` 脚本，二者读取 Python 生成的同一份 `results/input.csv`。Sysplorer 的 `.mo` 模型按同一数学定义采样生成输入；比较时也检查输入数值，不能只比较输出。

```powershell
python run_lab.py --compare
```

查看 `results/comparison.md` 与 `comparison.json`。缺少结果文件显示 `not_run`，尝试运行但未取得结果可显示 `blocked`，均不能解释为通过；有结果仍需检查时间轴、输入、输出及幅相指标。CSV 为 `t,x,y` 三列，时间严格递增，2001 行，双精度。

| 核验项 | 口径 |
|---|---|
| 时间轴 | 0～2 秒，每隔 0.001 秒，含两端；误差 < 1e-12 s |
| 输入和全序列输出 | 最大绝对误差 < 1e-10，包含启动瞬态 |
| 幅值与相位 | 在 0.1≤t<1.9 同时拟合 50/250 Hz 正弦、余弦与常数 |
| 250 Hz 残余 | 幅度 < 1e-12 视为数值零，不比较尾数排软件名次 |

为什么不直接取 2001 点 FFT 的某个谱线作为精确幅值？频率分辨率为 1000/2001 Hz，50 Hz 与 250 Hz 不恰好落在其频点上。联合拟合用于核验已知频率，不能代替一般未知信号的频谱分析。

若结果错开一格，应检查事件前后值、采样起点和初始状态，不要通过平移曲线或插值掩盖实现差异。零初始状态下前 M−1 个样本不满足无限长正弦的稳态公式。
