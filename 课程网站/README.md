# 课程网站

此目录预留给现有 Quarto 课程站。当前尚未导入网站源码或发布 GitHub Pages。

## 导入方案

保留现有 `ch1/` 至 `ch7/`、`_cards/`、`microlectures/` 结构，迁入讲义、实验代码、图片、交互页面和微课文字资料。

网站发布流程计划为：更新源码 → 自动检查 → Quarto 构建 → GitHub Pages 发布。视频由 Google Drive 提供，不随网站构建下载或复制。

## 微课页面

每条微课保留固定页面地址，展示封面、学习目标、视频播放入口、字幕和对应讲义链接。嵌入播放应同时提供“在网盘中打开”入口。

Drive 分享链接不是 MP4 文件直链，不可直接替换现有 HTML `<video>` 的 `src`。切换至 Drive 播放器前，应验证章节跳转、字幕、倍速及浅色／深色版本的行为；无法保留的自定义操作需要改为清晰的链接或版本选择。

## 发布前检查

- 将教师电脑绝对路径改为可下载的代码链接与学生可配置的运行说明。
- 更新“第3章样板”等旧介绍以及页脚信息。
- 只复制网页播放所需的资源，排除制作缓存与测试文件。
- 在 Pages 仓库子路径下检查导航、搜索、公式、图片和下载链接。
- 用未登录浏览器、手机与目标教学网络验证视频权限和播放。

Pages 上线后，再将真实可访问的网站链接加入仓库首页和课件。
