# 2.2-B 学生任务：从脉冲分解到卷积

先手算与预测，再运行程序核对。提交时保留错误与修正理由。

1. 把x=[1,2,3,4]（索引0…3）写成四个加权单位采样序列之和；写出各项对应的系统响应。分别指出用了线性还是时不变。
2. 对h=[3,2,1]（索引0…2），在同一k轴上画h[k]、h[−k]和h[2−k]。为什么最后一个不是简单画出h[k−2]？
3. 独立求n=3、4、5处的输出：列出各项乘积，再求和。完整卷积长度是多少？没有重叠时输出怎样？
4. 数值不变，把输入起点设为−1、响应起点设为2，写出输出的时间索引。解释数学y[n]与MATLAB数组y(i)的对应。
5. 将h改为[1,0,0.5]，先解释这个系统做了什么，再计算输出。若fs=1000Hz，两点延迟对应多长时间？
6. 比较conv(x,h)与filter(h,1,x)的返回长度。怎样保留尾部，才能公平比较完整结果？

提交：一张翻转平移图、一张逐项乘积表、带索引的完整输出、一次程序对照。另写明本片系统假设；不要把回声示意当作实测。
