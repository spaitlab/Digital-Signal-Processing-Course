# 2.3-B 学生任务：表达式与ROC一起给出

先写理论判断，再拖动项数或运行脚本，记录预期与观察是否一致。

1. 分别画出0.8ⁿu[n]与−0.8ⁿu[−n−1]的前几个非零样本，标出索引和符号。解释左边序列为什么不含n=0。
2. 从双边z变换定义推导两条几何级数。左边用m=−n换索引，写清求和起点和负号，再写各自ROC。
3. 固定z=0.4，比较两条序列的N=5、10、20、40项部分和。分式有有限值是否足以说明级数收敛？
4. 令|z|=0.8、角度π/3。记录末项模与部分和轨迹，用级数收敛的必要条件解释观察；不要仅以图形“没变大”判断。
5. 分别考察单位圆是否属于两条序列的ROC。能否直接把同一个分式代入z=exp(jω)，当作两者的通常DTFT？说明理由。
6. 写出左边级数在z=0的值，并说明为什么不能直接在含z⁻¹的未化简式中代零。

提交：两条序列图、两段几何级数推导、参数与部分和表、包含ROC的完整结论。图上注明N为项数，轨迹采用何种缩放。
