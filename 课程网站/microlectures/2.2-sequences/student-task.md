# 2.2-A 序列与周期性：学生任务

先预测再运行，本页不附参考答案。

1. 画出δ[n−2]与−δ[n−2]，标出不为0的位置和值。
2. 将从n=0开始的[1,2,−1,1]写成加权单位采样序列之和。
3. 对cos(0.3πn)，为什么20/3不能直接作为离散周期？20与40在周期意义上有何区别？
4. 画单位圆相位步进，说明0.3π与0.3的单位相同但步长不同。
5. 固定cos(0.3n)，平移21比较。看起来相近与满足周期定义有什么差别？
6. 只画120个点或只检验若干平移，能证明无限序列非周期吗？说明本例真正使用的数学依据。
7. 若在一个位置发现x[n+N]=x[n]，可以断定N为周期吗？
